# Platform Strategy

"Platform strategy" in the AI corpus refers to the structural argument that AI is a platform-shifting technology with characteristics distinct from prior software waves. The frame originates in Stratechery's analysis but has broader uptake in industry and policy commentary.

The principal characteristics of AI-as-platform-shifting-technology are: (1) **capabilities scale with inference cost** — a model's effective capability depends on inference parameters and context, not on user count (the conventional platform metric); (2) **models are opaque to integrators** — downstream integrators can use the model's outputs but cannot inspect its internals; (3) **distribution advantages tilt toward incumbents** — frontier labs with chat-product distribution (ChatGPT, Claude, Gemini) and API integration (Azure, AWS Bedrock) have compounding distribution advantages; (4) **business-model diversity** — frontier labs vary on API vs. consumer-product positioning, complicating the value-capture question.

The substantive comparison is to prior platform-shifting technologies. Databases (1970s-1980s) shifted business economics by enabling query-driven data products; browsers (1990s) shifted distribution economics by collapsing the desktop software barrier; social platforms (2000s) shifted attention economics by capturing user data; mobile platforms (2007-) shifted distribution economics via app stores. Each shift produced new value-capture structures (Oracle in databases, Microsoft in browsers, Google/Meta in social, Apple/Google in mobile). AI is the next such shift, with frontier labs in corresponding positions.

The strategic implications for AI incumbents and challengers are asymmetric. Incumbents with data, distribution, and infrastructure moats can ride the platform shift. New entrants without these have to choose between the closed-frontier API strategy, the open-weight provider strategy, the vertical-AI-product strategy, or the narrow-application strategy. Each has different return profiles, different regulatory exposures, and different procurement-power dynamics.
